# 🎵 YMusic CLI

TUI-плеер для **Яндекс Музыки** прямо в терминале.

![Python](https://img.shields.io/badge/python-3.14+-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## Возможности

- 🌊 **Моя Волна** — персональное радио с обратной связью
- ❤️ **Любимые треки** — ваши лайкнутые треки
- 📁 **Плейлисты** — все ваши плейлисты
- 🔍 **Поиск** — поиск по всей медиатеке Яндекса
- 🎛️ **Полноценный плеер** — play/pause, next/prev, seek, volume, repeat, shuffle
- 👍👎 **Лайки/дизлайки** — влияют на рекомендации в реальном аккаунте
- 🔐 **OAuth авторизация** — Device Flow или токен вручную

## Требования

- Python 3.14+
- `mpv` (установлен в системе)
- Аккаунт Яндекс с подпиской **Плюс** (для полных треков)

## Установка

```bash
# Клонирование
git clone <repo-url>
cd Ymusic_Cli

# Установка через uv
uv sync

# Запуск
uv run ymusic
# или
uv run python -m ymusic_cli
```

## Горячие клавиши

| Клавиша   | Действие              |
|-----------|----------------------|
| `Space`   | Play / Pause         |
| `n`       | Следующий трек       |
| `p`       | Предыдущий трек      |
| `=` / `+` | Громкость +          |
| `-`       | Громкость -          |
| `←` / `→` | Перемотка ±5 сек     |
| `r`       | Переключить повтор   |
| `s`       | Переключить шаффл    |
| `l`       | Лайк текущий трек    |
| `d`       | Дизлайк (не рекоменд)|
| `1-4`     | Навигация по секциям |
| `/`       | Фокус на поиск       |
| `q`       | Выход                |

## Авторизация

При первом запуске откроется экран логина. Два способа:

1. **Токен вручную**: перейдите по ссылке, скопируйте токен из URL после авторизации.
2. **Device Code**: нажмите кнопку, откройте URL в браузере, введите код.

Токен сохраняется в `~/.config/ymusic-cli/config.json`.
