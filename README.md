# 🎵 YMusic CLI

Трушный консольный плеер для **Яндекс Музыки** в стиле `cmus` / `mocp` с поддержкой Unix CLI и `fzf`.

![Python](https://img.shields.io/badge/python-3.14+-blue)
![Style](https://img.shields.io/badge/style-cmus-brightgreen)
![License](https://img.shields.io/badge/license-MIT-green)

---

## ⚡ Быстрый старт

```bash
# Запустить cmus-подобный полноэкранный TUI плеер:
uv run ymusic

# Или интерактивно выбрать трек из любимых через fzf:
uv run ymusic fzf

# Или включить Мою Волну прямо в консоли:
uv run ymusic wave

# Или найти и послушать трек:
uv run ymusic play "Slipknot"

# Или вывести список любимых треков (tab-separated, для unix-пайплайнов):
uv run ymusic liked -n 20
```

## 🎹 Cmus / Vim Горячие клавиши (в TUI)

### Навигация (Vim)
| Клавиша | Действие |
|:---|:---|
| `j` / `↓` | Вниз на 1 трек |
| `k` / `↑` | Вверх на 1 трек |
| `g` / `Home` | В начало списка |
| `G` / `End` | В конец списка |
| `Ctrl+D` / `Ctrl+U` | На полстраницы вниз / вверх |
| `Enter` | Воспроизвести выбранный трек / открыть плейлист |
| `Backspace` / `Esc` | Назад из плейлиста к списку плейлистов |

### Управление воспроизведением (cmus standard)
| Клавиша | Действие |
|:---|:---|
| `c` или `Space` | Пауза / продолжить |
| `b` или `n` | Следующий трек |
| `z` или `p` | Предыдущий трек |
| `x` | Начать текущий трек сначала |
| `v` | Остановить воспроизведение |
| `+` / `=` | Громкость +5% |
| `-` / `_` | Громкость -5% |
| `h` / `←` | Перемотка -5 секунд |
| `l` / `→` | Перемотка +5 секунд |
| `H` / `L` | Перемотка -30s / +30s |
| `r` | Режим повтора (off → all → one) |
| `s` | Перемешивание (shuffle) |

### Библиотека и рекомендации
| Клавиша | Действие |
|:---|:---|
| `a` | Поставить лайк (❤️) |
| `d` | Дизлайк (👎 / не рекомендовать + пропуск) |
| `u` | Перезагрузить текущий список из Яндекса |

### Вкладки (Views) и Командная строка
| Клавиша | Действие |
|:---|:---|
| `1` | **Моя Волна** (автоматический бесконечный поток рекомендаций с фидбэком) |
| `2` | **Любимые треки** (все ваши лайкнутые композиции) |
| `3` | **Плейлисты** (список ваших плейлистов; `Enter` чтобы открыть треки) |
| `4` | **Поиск** |
| `/` | Быстрый поиск внизу экрана (ввести запрос и нажать `Enter`) |
| `:` | Командный режим (`:q`, `:wave`, `:liked`, `:vol 80`, `:seek +15`, `:help`) |
| `?` | Всплывающая шпаргалка со всеми клавишами |
| `q` | Выход |

## 🛠️ CLI режим (Unix Philosophy)

```bash
# Информация об аккаунте и подписке
uv run ymusic status

# Интерактивный fzf-селектор треков
uv run ymusic fzf

# Запуск Моей Волны прямо в консоли с горячими клавишами
uv run ymusic wave

# Вывод треков для скриптов / fzf / dmenu / rofi
uv run ymusic liked | grep "Rock"
```

## ⚙️ Конфигурация

Конфиг хранится в `~/.config/ymusic-cli/config.json`:

```json
{
  "token": "y0_...",
  "volume": 70,
  "quality": "high",
  "cache_dir": "/home/anhelm/.cache/ymusic-cli"
}
```

Логи пишутся в `~/.cache/ymusic-cli/ymusic.log` (не засоряют консоль).
