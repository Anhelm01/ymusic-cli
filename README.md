# YMusic CLI

Консольный плеер для **Яндекс Музыки** со строгим терминальным интерфейсом, скользящим окном очереди, автоматической очисткой экрана, спектроанализатором и авто-авторизацией через браузер.

Кроссплатформенный: полная совместимость с Linux и Windows.

---

## Возможности

- **Категории одной цифрой (1-6)**:
  - `1`: Волна (Моя Волна, радио)
  - `2`: Лайки (Избранные треки)
  - `3`: Плейлисты (или `3 <N>` открыть плейлист N)
  - `4`: Поиск (или `4 <запрос>`)
  - `5`: Очередь (текущий плейлист)
  - `6`: Текст (слова текущей песни)
- **Компактная 3-трековая таблица**:
  - `<< Предыдущий` (или `<< Ранее`)
  - `>> Играет` (или `* Выбран`)
  - `>> Следующий` (или `>> Далее`)
  - Для вывода полного списка доступен флаг `all` (например: `liked all`, `queue all`).
- **Авто-очистка терминала**: экран автоматически обновляется при смене вкладок и переключении треков без накопления простыней логов.
- **Безопасность токенов**: токен сохраняется строго в системном профиле пользователя и никогда не попадает в папку сборки или репозиторий.
- **Автоматическая авторизация через браузер (`ymusic auth`)**:
  - Скрипт генерирует код устройства, копирует его в буфер обмена и сам открывает страницу `https://ya.ru/device` в браузере.
  - После подтверждения в браузере скрипт забирает токен, сохраняет в защищенную конфигурацию и завершает работу.
- **Интерактивный спектрограф (`vis`)**:
  - Полноэкранный ASCII-анализатор спектра с физикой затухания и управлением треками в реальном времени.

## Быстрый старт

### Запуск через uv / python:
```bash
# Установка зависимостей:
pip install -r requirements.txt

# Авторизация (откроет браузер и сохранит токен):
python -m ymusic_cli auth

# Запуск интерактивного плеера:
python -m ymusic_cli

# Или сразу Моя Волна:
python -m ymusic_cli 1
```

### Запуск скомпилированного бинарника:
```bash
# Linux:
./dist/ymusic

# Windows:
dist\ymusic.exe
```

---

## Сборка в автономный исполняемый файл

Сборка осуществляется кроссплатформенным скриптом `build.py` на базе PyInstaller:

```bash
# Установка зависимостей сборки:
pip install -r requirements-dev.txt

# Компиляция бинарника:
python build.py
```

Результат:
- **Linux**: `dist/ymusic` (одиночный бинарник без внешних python-зависимостей)
- **Windows**: `dist/ymusic.exe`

> **Безопасность:** Скрипт сборки проверяет и гарантирует, что локальный `config.json` и файлы токенов не упаковываются в исполняемый файл.

## Команды управления

| Команда | Описание |
|:---|:---|
| `1` | Категория 1: Волна (запуск радио «Моя Волна») |
| `2` | Категория 2: Лайки (Избранное) |
| `3` / `3 <N>` | Категория 3: Плейлисты (или открыть плейлист N) |
| `4` / `4 <запрос>` | Категория 4: Поиск (или сразу искать трек) |
| `5` | Категория 5: Очередь (компактное 3-трековое окно) |
| `6` | Категория 6: Текст (слова текущей песни) |
| `vis` | Интерактивный ASCII спектральный визуализатор (`q` или `Esc` для возврата) |
| `now` | Карточка трека с кассетой и прогресс-баром |
| `play <N>` | Воспроизвести трек номер N |
| `n` / `next` | Следующий трек (с автоподгрузкой Волны) |
| `p` / `prev` | Предыдущий трек |
| `pause` | Пауза / продолжить |
| `stop` | Остановить воспроизведение |
| `seek +/-N` | Перемотка на N секунд вперед/назад |
| `vol <0-100>` / `vol +/-N` | Управление громкостью |
| `repeat` | Переключение режима повтора: off -> all -> one |
| `shuffle` | Перемешивание очереди |
| `like` / `dislike` | Поставить лайк [+] / дизлайк [-] |
| `auth` | Обновить токен через браузер |
| `clear` / `cls` | Очистить экран |
| `status` | Статус аккаунта и подписки |
| `help` | Список всех команд |
| `q` / `quit` | Выход |

## Расположение файлов конфигурации

Конфигурация и токен авторизации хранятся в защищенном пользовательском каталоге операционной системы:

- **Linux / macOS**: `~/.config/ymusic-cli/config.json` (с правами доступа `0600`)
- **Windows**: `%APPDATA%\ymusic-cli\config.json`

Также поддерживается переменная окружения `YANDEX_MUSIC_TOKEN`.
