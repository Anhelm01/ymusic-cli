# 🎵 YMusic CLI

Трушный консольный плеер для **Яндекс Музыки** с киберпанк/ретро ASCII-графикой, вкладками, анимацией кассеты, текстами песен и спектральным визуализатором.

![Style](https://img.shields.io/badge/style-retro--cyberpunk-cyan)
![License](https://img.shields.io/badge/license-MIT-green)

---

## ✨ Особенности визуала

- 👾 **ASCII Cyberpunk Banner**: ретро-логотип с бейджами профиля, статуса Плюса и качества звука (HQ 320k).
- 📑 **Табы (Вкладки)**: `[1] 🌊 Моя Волна`, `[2] ❤️ Избранное`, `[3] 📁 Плейлисты`, `[4] 🔍 Поиск`, `[5] 📜 Очередь`, `[6] 🎤 Текст`.
- 📼 **Анимированная кассета**: вращающиеся катушки `◜(●)◝`, пульсирующий эквалайзер и карточка текущего трека (`now`).
- ⚡ **Real-time ASCII Spectrum Visualizer**: интерактивный анализатор спектра (`vis`) с градиентными столбиками и хоткеями.
- 🎤 **Тексты песен (`lyrics`)**: автоматическая подгрузка и оформление текстов треков прямо в терминале.
- 🎛️ **Bottom Toolbar**: информативная строка состояния в prompt_toolkit над строкой ввода.

## ⚡ Быстрый старт

```bash
# Запуск интерактивного плеера:
ymusic

# Или запуск сразу в режиме «Моя Волна»:
ymusic wave

# Или просмотр любимых треков:
ymusic liked

# Найти и включить трек:
ymusic play "Daft Punk"

# Интерактивный спектральный визуализатор:
ymusic vis

# Статус аккаунта и подписки:
ymusic status
```

## 🎛️ Команды в интерактивной оболочке

| Команда | Описание |
|:---|:---|
| `tab <1-6>` / `t1`-`t6` | Переключение между табами (Волна, Избранное, Плейлисты, Поиск, Очередь, Текст) |
| `vis` / `visualizer` | Интерактивный ASCII спектральный визуализатор (`q` или `Esc` для возврата) |
| `lyrics` / `text` | Показать текст текущей песни (Таб 6) |
| `now` | Карточка трека с анимированной кассетой и прогресс-баром |
| `wave` | Запустить радио «Моя Волна» (Таб 1) |
| `liked` | Показать любимые треки (Таб 2) |
| `playlists` | Список ваших плейлистов (Таб 3) |
| `open <N>` | Открыть плейлист номер N |
| `search <query>` | Поиск треков (Таб 4) |
| `play <N>` | Воспроизвести трек номер N |
| `queue` | Показать очередь треков (Таб 5) |
| `n` / `next` | Следующий трек (с автоподгрузкой Волны) |
| `p` / `prev` | Предыдущий трек |
| `pause` | Пауза / продолжить |
| `stop` | Остановить воспроизведение |
| `seek +/-N` | Перемотка на N секунд вперед/назад |
| `vol <0-100>` / `vol +/-N` | Управление громкостью |
| `repeat` | Переключение повтора (off → all → one) |
| `shuffle` | Перемешивание очереди |
| `like` / `dislike` | Поставить лайк / дизлайк |
| `status` | Статус аккаунта и подписки |
| `help` | Список всех команд |
| `q` / `quit` | Выход |

## ⚡ Хоткеи в визуализаторе (`vis`)

При открытии визуализатора клавиши работают напрямую в реальном времени без нажатия Enter:

- `Space`: Пауза / Play
- `n` / `p`: Следующий / Предыдущий трек
- `+` / `-`: Громкость
- `l`: Лайк текущему треку
- `s`: Shuffle
- `r`: Режим повтора
- `q` / `Esc`: Выход из визуализатора обратно в оболочку

## ⚙️ Конфигурация

Конфиг хранится в `~/.config/ymusic-cli/config.json`:

```json
{
  "token": "y0_...",
  "volume": 70,
  "quality": "high",
  "cache_dir": "/home/anhelm/.cache/ymusic-cli"
}
```

Логи пишутся в `~/.cache/ymusic-cli/ymusic.log` (не засоряют консоль).
