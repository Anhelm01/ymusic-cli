# YMusic CLI

<p align="left">
  <strong><a href="README.md">English</a></strong> | <strong>Русский</strong>
</p>

**YMusic CLI** — современный, быстрый и ультра-легковесный (~6.5 МБ) консольный плеер для **Яндекс Музыки** с адаптивным мини-интерфейсом, динамической строкой трека, скользящим окном очереди и автоматической авторизацией через браузер.

Кроссплатформенный: полноценная поддержка **Linux** и **Windows** (10 / 11).

---

## Основные возможности

- **Мгновенная навигация цифрами и словами (1–4)**:
  - `1` / `wave` / `волна`: **Моя Волна** — бесконечный персональный поток музыки с автоподгрузкой.
  - `2` / `liked` / `лайки`: **Избранное** — ваша библиотека лайкнутых треков.
  - `3` / `playlists` / `плейлисты`: **Плейлисты** — просмотр личных и рекомендованных плейлистов (`3 <N>` для выбора).
  - `4` / `search` / `поиск`: **Поиск** — мгновенный поиск треков, исполнителей и альбомов (`4 <запрос>`).
- **Адаптивный Mini-TUI**:
  - Двухстрочный компактный заголовок, автоматически подстраивающийся под ширину окна терминала (от лаконичных иконок до развернутых названий).
  - Автоматическая очистка и перерисовка экрана после каждой команды — интерфейс не дублируется и не забивает консоль.
- **Двуязычное управление без переключения раскладки**:
  - Горячие клавиши работают как в английской, так и в русской раскладке (`c`/`с` — пауза, `n`/`т` — след., `p`/`з` — пред., `l`/`д` — лайк, `d`/`в` — дизлайк).
- **Интеллектуальная компактная очередь (3 трека)**:
  - `<< Предыдущий`
  - `>> Играет`
  - `>> Следующий`
  - Для просмотра полного списка треков доступен флаг `all` (например: `liked all`, `2 all`).
- **Рекордно легкий бинарник**:
  - Размер standalone-сборки снижен до **~6.5 МБ** на Linux (без необходимости устанавливать Python).
- **Безопасная авто-авторизация (`auth`)**:
  - Быстрый вход по технологии **Device Auth**: плеер сам генерирует код, копирует в буфер и открывает `https://ya.ru/device`. Никаких ручных поисков токена в DevTools!
  - Токены хранятся строго в защищенном профиле пользователя ОС и никогда не попадают в репозиторий.

---

## Требования

1. **Аудио-движок mpv**: YMusic CLI использует `libmpv` для воспроизведения аудио высокого качества с минимальным потреблением ресурсов.
2. *(Опционально для запуска из исходников)*: Python **3.10+** и менеджер пакетов (`uv` или `pip`).

## Пошаговое руководство для Linux

### Шаг 1. Установка системных зависимостей (mpv)

Установите `mpv` через пакетный менеджер вашего дистрибутива:

- **Ubuntu / Debian / Linux Mint**:
  ```bash
  sudo apt update
  sudo apt install -y mpv libmpv-dev
  ```
- **Arch Linux / Manjaro**:
  ```bash
  sudo pacman -S mpv
  ```
- **Fedora / RHEL**:
  ```bash
  sudo dnf install -y mpv mpv-libs-devel
  ```
- **openSUSE**:
  ```bash
  sudo zypper install mpv libmpv2
  ```

---

### Шаг 2. Запуск плеера на Linux

#### Вариант А: Запуск готового исполняемого файла (без установки Python)

1. Скачайте архив релиза (`ymusic-v0.3.0-linux-x64.tar.gz`) из GitHub Releases:
   ```bash
   tar -xzf ymusic-v0.3.0-linux-x64.tar.gz
   cd ymusic-v0.3.0-linux-x64
   ```
2. Выдайте права на исполнение:
   ```bash
   chmod +x ymusic
   ```
3. *(Рекомендуется)* Добавьте бинарник в системный путь, чтобы запускать команду `ymusic` из любой директории:
   ```bash
   mkdir -p ~/.local/bin
   cp ymusic ~/.local/bin/
   ```
   *(Убедитесь, что `~/.local/bin` есть в вашей переменной `$PATH`)*.

4. Запустите плеер:
   ```bash
   ymusic
   ```

#### Вариант Б: Запуск из исходников (через uv или venv)

- **Быстрый способ через uv** (рекомендуется):
  ```bash
  # Установка зависимостей в виртуальное окружение:
  uv sync

  # Запуск плеера:
  uv run ymusic
  ```

- **Стандартный способ через Python venv и pip**:
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  python3 -m ymusic_cli
  ```

## Пошаговое руководство для Windows

### Шаг 1. Установка аудио-бэкенда (mpv)

Плееру необходима библиотека `libmpv` / исполняемый файл `mpv.exe` в системном пути:

- **Способ 1 (через winget — встроен в Windows 10/11)**:
  ```powershell
  winget install mpv.net
  # или
  winget install mpv.mpv
  ```
- **Способ 2 (через Scoop)**:
  ```powershell
  scoop install mpv
  ```
- **Способ 3 (через Chocolatey)**:
  ```powershell
  choco install mpv
  ```
- **Способ 4 (вручную)**:
  1. Скачайте архив mpv с [SourceForge / GitHub](https://sourceforge.net/projects/mpv-player-windows/files/).
  2. Распакуйте `libmpv-2.dll` (или `mpv.exe`) в папку с `ymusic.exe` или добавьте папку с mpv в системную переменную `PATH`.

> [!TIP]
> **Рекомендуемый терминал для Windows**: используйте современный **Windows Terminal** (доступен в Microsoft Store). Он корректно поддерживает ANSI-цвета, UTF-8 и шрифты Nerd Fonts.

---

### Шаг 2. Запуск плеера на Windows

#### Вариант А: Запуск готового `ymusic.exe`

1. Скачайте и распакуйте `ymusic-v0.3.0-windows-x64.zip`.
2. Откройте **Windows Terminal** (PowerShell или командную строку).
3. Запустите:
   ```powershell
   .\ymusic.exe
   ```

#### Вариант Б: Запуск из исходников в Windows

```powershell
# Создание и активация виртуального окружения
py -m venv .venv
.\.venv\Scripts\Activate.ps1

# Установка зависимостей
pip install -r requirements.txt

# Запуск интерактивного шелла
python -m ymusic_cli
```

## Авторизация (Device Auth)

При первом запуске плеер автоматически предложит войти в аккаунт Яндекс:

1. Запустите команду авторизации:
   ```bash
   ymusic auth
   ```
2. Плеер сгенерирует уникальный код устройства (например, `ABCD-1234`), **автоматически скопирует его в буфер обмена** и откроет страницу подтверждения:
   ```
   https://ya.ru/device
   ```
3. В браузере нажмите **Ctrl+V** (Вставить), подтвердите подключение устройства.
4. Плеер автоматически перехватит токен, надежно сохранит его в конфигурации и выведет имя пользователя с подтверждением активной подписки Яндекс Плюс.

### Альтернативная авторизация:
Если вы уже знаете свой OAuth-токен:
```bash
ymusic auth <ВАШ_ТОКЕН>
```
Или передайте его через переменную окружения:
- **Linux**: `export YANDEX_MUSIC_TOKEN="ваш_токен"`
- **Windows (PowerShell)**: `$env:YANDEX_MUSIC_TOKEN="ваш_токен"`

## Команды и горячие клавиши

### Быстрый запуск из терминала:
| Команда | Описание |
|:---|:---|
| `ymusic` | Запуск интерактивного шелла |
| `ymusic 1` или `ymusic wave` | Запустить «Мою Волну» сразу при старте |
| `ymusic 2` или `ymusic liked` | Открыть избранные треки |
| `ymusic play <название>` | Найти и сразу воспроизвести трек |
| `ymusic search <запрос>` | Выполнить поиск по библиотеке |
| `ymusic status` | Показать статус аккаунта и выйти |
| `ymusic update` / `auth` | Принудительно обновить токен через браузер |
| `ymusic --version` / `-v` | Показать версию программы |
| `ymusic --help` / `-h` | Показать справку по параметрам CLI |

### Управление внутри интерактивного шелла:

#### Разделы (ввод цифры или слова):
- `1` / `wave` / `волна` — **Моя Волна** (бесконечное персональное радио)
- `2` / `liked` / `лайки` — **Лайки** (ваши избранные треки, компактно 3 штуки)
- `2 all` — Показать полный список лайков
- `3` / `playlists` / `плейлисты` — **Плейлисты** (список ваших плейлистов)
- `3 <номер>` — Открыть и загрузить плейлист под номером N
- `4 <запрос>` / `поиск <запрос>` — **Поиск** по Яндекс Музыке

#### Управление воспроизведением (работает в латинице и кириллице):
- `c` / `pause` / `с` — Приостановить / возобновить воспроизведение
- `n` / `next` / `т` — Следующий трек (в Моей Волне треки подгружаются бесконечно)
- `p` / `prev` / `з` — Предыдущий трек
- `l` / `like` / `д` — Поставить лайк
- `d` / `dislike` / `в` — Поставить дизлайк (пропустить в Моей Волне)
- `now` — Показать компактную карточку играющего трека
- `seek +/-N` — Перемотка на N секунд (например, `seek +30` или `seek -15`)
- `vol <0-100>` — Установить уровень громкости (например, `vol 80`)
- `vol +/-N` — Изменить громкость на шаг (например, `vol +5` или `vol -10`)
- `repeat` — Переключение режима повтора: `off` -> `all` -> `one`
- `shuffle` — Перемешать список треков
- `stop` — Полная остановка

#### Системные команды:
- `clear` / `cls` — Очистить терминал
- `status` — Показать статус профиля и подписки
- `update` / `auth` — Обновить токен через браузер
- `help` — Показать справку по командам
- `q` / `quit` / `exit` / `выход` — Выйти из плеера

## Сборка автономных бинарников

Собрать автономный бинарник и сформировать архивы релиза можно с помощью `build.py`:

```bash
# Сборка бинарника и архивов релиза:
python build.py --package
```

### Результаты сборки:
- **Linux**: `dist/linux/ymusic` (одиночный бинарник, ~6.5 МБ) и архив `releases/ymusic-v0.3.0-linux-x64.tar.gz`.
- **Windows**: `dist/windows/ymusic.exe` и архив `releases/ymusic-v0.3.0-windows-x64.zip`.

> **Гарантия безопасности сборки:**
> Перед сборкой скрипт `build.py` проверяет репозиторий и блокирует случайное попадание любых токенов, `config.json` и личных данных в дистрибутив.

## Расположение файлов конфигурации и логов

Конфигурация хранится в защищенной директории пользователя ОС:
- **Linux**: `~/.config/ymusic-cli/config.json` (права `0600`)
- **Windows**: `%APPDATA%\ymusic-cli\config.json`
- **Логи**: `~/.cache/ymusic-cli/ymusic.log` (Linux) или `%LOCALAPPDATA%\ymusic-cli\ymusic.log` (Windows).

## Решение проблем

### 1. `Cannot find libmpv` или `mpv is not installed`
- **Linux**: Убедитесь, что установлена библиотека `libmpv1` / `libmpv2` / `libmpv-dev` (`sudo apt install libmpv-dev` или `sudo pacman -S mpv`).
- **Windows**: Убедитесь, что `libmpv-2.dll` находится в системном `PATH` или положена рядом с `ymusic.exe`.
